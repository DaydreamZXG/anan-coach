基期比重：现期比重乘增长率修正

mc_ziliao_jiqi_bizhong_01 资料分析/比重问题/基期比重 限时 70 秒/题 抽样：exact_display_path 状态：draft

识别信号

题干问上年、上期或基期某部分占总体的比重

精度规则

先用方向排除；选项接近时再计算修正系数

基期比重公式里整体增速在分子，部分增速在分母

适用

  • 已知部分现期量、整体现期量及二者增长率
  • 题干明确问过去时期的比重

排除

  • 只问现期比重
  • 材料已直接给出基期部分和基期整体

步骤

  1. 先算现期比重 = 部分现期 / 整体现期
  2. 基期比重 = 现期比重 x (1 + 整体增速) / (1 + 部分增速)
  3. 部分增速大于整体增速时，基期比重小于现期比重
  4. 选项粗时先用升降关系排除，再估修正系数

常见错因

  • base_proportion_growth_order_wrong：把修正系数写成 (1 + 部分增速) / (1 + 整体增速)
  • base_proportion_direction_wrong：没先用增速大小判断基期比重相对现期的方向

识别信号

题干问平均每、平均拥有、人均、日均、单位里程等现期平均值

精度规则

范围选项估到区间即可；精确选项保留两位有效数字

平均数题最常错在单位，不是公式

适用

  • 同一时期给出总量和份数
  • 题干出现平均、每、单位、人均、日均

排除

  • 问平均数增长率
  • 问基期平均数

步骤

  1. 先把被平均的总量圈出来，再圈份数或对象数
  2. 平均数 = 总量 / 份数
  3. 单位不一致时先统一数量级
  4. 选项范围型题只需估到落入区间

常见错因

  • average_total_count_reversed：把份数除以总量
  • average_unit_not_converted：万、亿、万人次等单位没有先统一

基期平均数：现期平均数反推

mc_ziliao_jiqi_pingjunshu_01 资料分析/平均数问题/基期平均数 限时 70 秒/题 抽样：exact_display_path 状态：draft

识别信号

题干问上年、上期或基期的平均每、人均、单位量

精度规则

先判方向；选项接近时保留一位小数核算修正系数

基期平均数修正中，份数增速在分子，总量增速在分母

适用

  • 已知总量现期、份数现期及二者增长率
  • 题干明确问过去时期平均数

排除

  • 只问现期平均数
  • 材料直接给出基期总量和基期份数可直接相除

步骤

  1. 先算现期平均数 = 总量现期 / 份数现期
  2. 基期平均数 = 现期平均数 x (1 + 份数增速) / (1 + 总量增速)
  3. 总量增速大于份数增速时，基期平均数小于现期平均数
  4. 先用方向排除，再估修正系数

常见错因

  • base_average_growth_order_wrong：把总量和份数的增长率修正顺序写反
  • base_average_direction_wrong：没用总量增速和份数增速判断基期平均数方向

识别信号

题干问是几倍、比值、强度、密度、单位量或 A 约为 B 的多少

精度规则

范围选项只估到区间；精确倍数题保留两位有效数字

看到“增长速度的几倍”，先算两个增长率，不是两个原量相除

适用

  • 题干需要把两个同口径量做除法
  • 选项为倍数、范围或单位强度

排除

  • 问比重且有明确部分整体关系
  • 问增长率的倍数，需要先求两个增长率

步骤

  1. 把题干翻译成 A / B，先写清谁除以谁
  2. 单位不同先统一，尤其万、亿、日均、公里
  3. 选项为范围时估首两位即可
  4. 若问增长速度的倍数，先分别求两个增长率再相除

常见错因

  • ratio_direction_reversed：A 是 B 的几倍时把 B / A
  • ratio_nested_rate_skipped：问增长速度倍数时直接用原量相除
