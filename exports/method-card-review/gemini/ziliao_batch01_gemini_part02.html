增长量计算：优先用现期和率

mc_ziliao_zengzhangliang_jisuan_01 资料分析/增长量/增长量计算 限时 55 秒/题 抽样：exact_display_path 状态：draft

识别信号

题干问增加了多少、增长量、同比增量或环比增量

精度规则

r 可化成常见分数时用 n+1 公式；不能化分数时按选项差距估算

现期乘增长率算出来偏大，常是陷阱项

适用

  • 已知现期量和增长率
  • 或材料直接给出现期量和基期量

排除

  • 问增长率
  • 问多个对象增长量大小排序

步骤

  1. 有现期和基期时，增长量 = 现期 - 基期
  2. 有现期和增长率时，增长量 = 现期 x r / (1 + r)
  3. r 接近 1/n 时，用现期 / (n + 1) 速算增长量
  4. 负增长时增长量为负，问减少量时取绝对值

常见错因

  • growth_amount_use_current_times_rate：直接用现期乘增长率，少除以 (1 + r)
  • growth_amount_negative_misread：没区分增长量为负和减少量为正

增长量比较：大大则大，一大一小再算

mc_ziliao_zengzhangliang_bijiao_01 资料分析/增长量/增长量比较 限时 60 秒/题 抽样：exact_display_path 状态：draft

识别信号

题干问哪个增长量最大、最小，或要求比较多个对象同比增量

精度规则

先用大大则大排除；只在一大一小时估算增长量

增长率最高不等于增长量最大

适用

  • 多个对象均给出现期量和增长率
  • 题干目标是增长量大小而不是增长率大小

排除

  • 只比较增长率
  • 数据口径不同，不能直接横比

步骤

  1. 同时比较现期量和增长率，现期大且率大则增长量必大
  2. 现期小且率小的对象可先排除
  3. 一大一小时，用现期 x r / (1 + r) 估算关键候选
  4. 只精算最接近的两个候选

常见错因

  • growth_amount_compare_rate_only：只按增长率大小比较增长量
  • growth_amount_compare_all_calculated：每个选项都完整计算，耗时过长

现期比重：先找部分和整体

识别信号

题干问某部分占总体的比重、占比或百分点差

精度规则

比重题先估首位；百分点差小于2时再保留一位小数

百分点是两个百分数直接相减，不再除以原比重

适用

  • 材料给出同一时期的部分量和总体量
  • 题干出现占、比重、占比、百分点

排除

  • 问上一期比重
  • 问两期比重变化

步骤

  1. 先圈部分量，再圈整体量，确认二者同一时期同一单位
  2. 比重 = 部分 / 整体
  3. 问百分点差时分别算两个比重再相减
  4. 选项粗时把整体化成便于除的整百、整千

常见错因

  • proportion_part_whole_reversed：把整体和部分放反
  • percentage_point_as_percent：把百分点差误当成百分比变化

两期比重：先看部分增速减整体增速

mc_ziliao_liangqi_bizhong_01 资料分析/比重问题/两期比重 限时 65 秒/题 抽样：exact_display_path 状态：draft

识别信号

题干问比重上升、下降或比上年提高几个百分点

精度规则

先判升降；选项只问方向不算幅度，问百分点再估现期比重乘增速差

比重变化的正负只看部分增速和整体增速的大小

适用

  • 已知部分现期量、整体现期量及二者增速
  • 题干比较两个时期的比重变化

排除

  • 只问现期比重
  • 缺少部分或整体的增长率

步骤

  1. 先比较部分增速 a 和整体增速 b
  2. a 大于 b，比重上升；a 小于 b，比重下降
  3. 变化幅度约为现期比重 x (a - b) / (1 + a)
  4. 只问升降时不用计算百分点

常见错因

  • two_period_proportion_direction_wrong：没用部分增速减整体增速判断升降
  • two_period_proportion_overcalculate：只问升降仍完整计算百分点，浪费时间
