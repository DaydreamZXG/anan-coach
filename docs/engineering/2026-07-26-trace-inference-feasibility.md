# 笔迹/动作流倒推思路：可行性判定与实施路线（2026-07-26）

四路代码级查证的结论（动作事件流、math-ink、题库颗粒度、错因体系），
所有断言可溯源到文件行号，详见本次查证工作流记录。

## 1. 判定：能做，分三级，当前卡在 L1

- **L1 行为叙事（已具备）**：14 种动作事件（选答/改答/排除/信心/草稿/暂停/批注增删…）
  按题聚合进不可变检查点；批注为归一化点序列（≤120 笔/题）；有轨迹回放与确定性动作分析。
- **L2 过程诊断（差采集精度）**：当前 atMs 是秒级（elapsedSeconds×1000）、批注笔画无逐点
  时序、无材料/段落锚点事件、擦除即丢几何、模考不采集、无跨题时间线。
- **L3 思路推断挂知识点（差消费与建模）**：cause_agent 四个冻结工具完全不读动作流与墨迹；
  错因结论是题组级不是单题级；能力建模只到科目级/模块级，知识点级为空。

## 2. 关键事实

### 2.1 数据资产比预期厚
- 题库 canonical v1：55,214 题（行测 53,011 / 申论 2,203）、occurrence 104,453、
  试卷 764、解析 53,011、知识点标签 557,844 行、知识片段 23,103。
- 知识粒度链：六模块（代码枚举）→ 题型/知识族/知识点（tag 数据态，如
  行测/资料分析/增长率）→ 题目。标签够细，**但只有数据态，没有受控词表**。
- math-ink（数量关系草稿纸）是被低估的资产：逐点毫秒时序（Date.now()）+
  MyScript 公式→LaTeX + 用户确认二段流程 + 全链审计。这是最接近
  「思路外化」的数据源，但识别结果只回填草稿文本，AI 零消费。

### 2.2 错因流水线骨架优秀、四个漏洞
AI 候选 + 用户终审（confirm/reject/replace/defer/skip）、证据引用强制、
争议暂停原则（PRD §8）。漏洞：① 错因绑题组不绑单题，聚合时摊派到模块；
② 用户改写全进 user_replacement 单桶不回流分类；③ 行测反证 counterevidence
硬编码 0，观测窗口未实现；④ 争议题在错因聚合 SQL 中无任何过滤。

### 2.3 companion 上下文注入深但有死路径
question ref 能拿到题干+材料+选项+答案+解析+作答轨迹+判分；但 attempt/material
ref 是死路径（只鉴权不产内容），批注/墨迹在所有注入路径中缺席。

## 3. 按题型的诚实覆盖评估

| 题型 | 倒推可行性 | 依据 |
| --- | --- | --- |
| 资料分析/数量关系 | 高 | 草稿纸公式流（逐点时序）+ 计算错误可对齐解析 |
| 判断推理 | 中 | 排除轨迹+批注划线有信号；图形推理 image_unsupported 整体缺位 |
| 言语理解 | 弱 | 思路外化少，主要靠画词与排除 |
| 政治/常识 | 无过程可倒推 | 知识型秒答，错因=knowledge_gap 即可 |
| 申论 | 另一条线 | 找点归因三分法已有（纯 AI 判定，缺用户确认环节） |

结论：不需要全题型倒推；过程型题型（资料/数量/判断）覆盖思路倒推的主要价值。

## 4. 实施路线

**第一期 · 采集补强（工程 1–2 周，越早越好——数据没采就永远丢了）**
1. atMs 换毫秒级单调时钟；补跨题会话时间线（QUESTION_CHANGED 事件）
2. 批注笔画加逐点 t（协议留了扩展位）；擦除改墓碑标记保留几何
3. 材料滚动/锚点进入事件流（MATERIAL_POSITION_CHANGED 记事件）
4. 模考开启同套采集；事件溢出加标记不静默丢弃

**第二期 · AI 消费（2–4 周）**
1. cause_agent 新增冻结工具 load_action_trace / load_ink_formulas
2. 错因结论下探单题级；user_replacement 文本回流分类；接通反证与争议过滤
3. 知识点受控词表 + 知识点级能力估计（55.7 万行标签已就位，等建模消费）

**第三期 · 效果标定（一个备考周期）**
内测 cohort 的错因确认率、复测通过率、无证据错因比率（PRD 安全指标）。
