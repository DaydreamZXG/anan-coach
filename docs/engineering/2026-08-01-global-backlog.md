## 2. 🔨 进行中：批注锚定改造（任务 #31/#32/#33）

目标：AI 能知道用户**具体标记了哪句原文**（不只"画了几笔"），荧光笔自由画，
三层一次做完（数据契约 + 前端 + AI 消费）。

| 层 | 内容 | 状态 |
| --- | --- | --- |
| **#31 数据契约** | `AnnotationAnchor{blockId, segmentIndex, segmentText}` 进后端 schema + 前端 `contracts.ts` + 生成类型 + 深拷贝 | ✅ 完成 |
| **#32 前端批注层** | 新增 `anchor.ts`（句段收集/归一化/最近句段命中/位移平移，7 测试）；批注层加荧光笔工具 + `segments` prop + 命中盖 anchor + 滚动跟随（路由 B）；练习页 `annotationSegments` 矩形表 + scroll 绑定 + 切题退出批注；手工标记笔迹带 anchor。typecheck/lint 干净 | ✅ 完成 |
| **#33 AI 消费** | `load_action_trace` 逐笔读 anchor 汇总 `anchoredSegments`（按时间排序、同段去重计数）+ `anchoredSummary` 人读摘要；provider prompt 指引（锚定=原文证据、分析认知动作、只引 anchor 原文不编造）；契约/提示版本 bump（action-trace @v2、prompt @v4、definition `2026-07-31.1`）；39 个定向测试全过、ruff 干净 | ✅ 完成 |

> **锚定改造整体结论**：三层已闭环 —— 笔迹落笔即解析成"标记了哪句原文"（anchor），滚动跟随让批注跟着题目走，AI 消费把标记文字当证据分析认知动作。下一步建议 staging 真机验证 + 冒烟回归。 |

设计要点（已定，不再讨论）：
- 批注层通过**最近句段命中**把笔迹坐标解析成锚定文字段，随笔画一起上报。
- 段落矩形表由 host（练习页）维护，滚动时**重算锚点 + 重绘**（路由 B）。
- 第一阶段只有**题干**段可选，选项不可选（后续再放开）。
- 旧笔迹无 `anchor` 字段 → 视为普通涂画，天然兼容。
