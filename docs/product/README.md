使用规则：

- 当前产品目标、用户闭环、领域边界和实施顺序以正式说明为准；
- 当前阶段、唯一开发焦点、完成状态和下一发布单元以开发路线图为准；
- 当前实现事实以代码、数据库迁移、生成契约和可重复测试为准；
- `.product-governance/` 是发布单元的机器可执行权威，但目前只覆盖部分轨道，不能冒充完整产品架构；
- `_archive/` 中的文件是历史证据，不再代表当前目标、状态或上线结论。

正式说明没有冻结具体 API、schema 或发布阈值。涉及跨域事实、数据生命周期、AI 权限或上线
门禁的实施，仍需在对应发布单元中形成依赖闭合的契约和验证证据。
