# 学习输入输出、拍题搜索与商业权益边界

> 历史归档：本文件不再作为当前产品、实现或上线状态权威。当前说明见
> `docs/product/anan-product-system-spec.md`。

> 状态：商业发布基线
> 日期：2026-07-12
> 适用：微信小程序、后续 App、后端学习大脑、题库与商业权益

## 1. 产品决策

小程序不是所有学习行为的容器，而是用户备考的**学习中枢**。用户可以在纸上、笔记 App、其他题库或线下课程中学习，但关键结果应能回到同一个学习大脑。

因此产品必须同时建立三条正式通道：

1. **导出执行**：把计划、题组、模考或申论任务生成可打印、可保存到笔记 App 的学习包。
2. **结果回流**：用户通过答案串、答题卡照片、题页标记或申论手写稿回传结果，继续复盘和复测。
3. **外部摄入**：用户拍摄或导入纸质题、错题、外部报告和申论材料，经识别、匹配和用户确认后成为个人证据。

三条通道共用版本、来源、确认和权益规则，不分别建立临时数据模型。

## 2. 权威数据对象

| 对象 | 用途 | 不可缺字段 |
|---|---|---|
| `source_artifact` | 用户上传的图片、PDF、文字或报告 | 所有者、来源声明、哈希、对象存储版本、保留期 |
| `recognition_revision` | OCR、版式分割、图形特征和用户修订 | 引擎/模型版本、区域置信度、修订轨迹 |
| `content_match` | 将外部内容匹配到自有或已授权题库 | 候选集、匹配方法、分数、题目版本、用户确认 |
| `offline_packet` | 可打印/导入的版本化学习包 | 任务版本、题目版本、顺序、答题卡编码、导出模板版本 |
| `answer_ingestion` | 纸上或外部作答的回流事件 | 作答来源、答案、用时类型、确认状态、关联学习包 |

原图、识别文本、题库匹配、AI 解释和用户结论必须分层保存，不得将 OCR 结果覆盖原图，不得将相似匹配冒充精确命中。

## 3. 打印、PDF 与笔记 App 导出

### 3.1 导出类型

- **今日纸笔包**：当日 1–3 个任务，包含任务原因、题目、答题区和回流入口。
- **专项训练包**：按模块、方法、难度、时长和待验证错因组卷。
- **标准模考包**：固定试卷版本、统一答题卡和完整交卷规则。
- **申论作答包**：材料、稳定段落编号、题目要求、答题纸和稿纸。
- **错题/复盘包**：仅导出用户拥有权限的题目、自己的作答和复盘，可选隐藏答案。
- **笔记包**：PDF 为正式交付格式；结构化文本和图片作为用户自有笔记的辅助导出。

### 3.2 回流协议

- 每份学习包都有不可猜测的短码/二维码，只定位用户已获授权的任务版本，不在码中暴露答案和 learner ID。
- 客观题支持手工录入答案串、逐题录入和拍摄标准答题卡。
- 申论支持逐页上传，自动检测页序，用户确认缺页、旋转、重复和低置信区域。
- 纸上作答无法产生可验证的逐题用时、改答和离开轨迹；用户可提供整卷用时或逐题自报用时，但证据等级低于程序内计时。
- 导出、下载和打印不等于已学习；只有答案回流、复盘或用户明确确认才生成学习证据。

### 3.3 版权边界

- 只能完整导出自有、已授权、公开许可或用户自己上传且有权使用的内容。
- 外部题库或课程截图可作为该用户的私人学习证据，不自动进入可向其他用户分发的题库。
- 导出件必须标识内容来源、题目版本、生成时间和使用范围。

## 4. 拍题、搜图与外部错题

### 4.1 统一入口

对用户统一命名为“拍题/导入学习资料”，不承诺每张图都能“搜到原题”。系统返回的结果必须明确属于哪一类：

1. **精确命中**：命中已授权题目的确定版本，可展示来源、答案和存量解析。
2. **相似候选**：展示 1–3 个候选及差异，必须由用户确认，不提前判分。
3. **未命中的 AI 解题**：保留原图和识别版本，显示不确定区域与推理依据，不冒充题库标准答案。
4. **无法可靠解析**：明确告知缺少的题干、图像、选项或材料，不使用补全内容给出假确定结论。

### 4.2 识别管线

```text
原始图片/PDF
  → 去重、旋转和质量检查
  → 题号/题干/选项/图形/材料/手写答案分区
  → OCR + 版式特征 + 图像特征
  → 精确指纹匹配
  → 文本/视觉混合召回
  → 候选重排并显示差异
  → 用户确认
  → 解析、复盘或仅存档
```

图形推理不依赖 OCR 作为主特征，使用感知哈希、图形嵌入、版式和选项相对位置。模型不能稳定区分线条、旋转、叠加或局部差异时，结果只能是“需补拍/需确认”，不能写入错因和能力画像。

### 4.3 记入个人学习大脑的条件

- 仅上传或搜索：记为“摄入行为”，不记为作答和掌握证据。
- 用户确认题目并录入原答案：记为外部作答证据，来源和条件不可缺失。
- 用户补充当时思路并确认 AI 候选错因：才可进入长期错误模式。
- 外部题的题目质量、答案真值或版本不可确认：可保存为个人错题，但暂停影响能力和计划。

## 5. 申论搜索与导入边界

| 用户提供的内容 | 可提供的能力 | 不能给出的结论 |
|---|---|---|
| 完整材料 + 题目要求 + 作答 | 原题匹配、要点来源、结构/表达/字数分析、区间评阅 | 人工阅卷等价的精确分数 |
| 完整材料 + 题目要求 | 原题搜索、材料标注、自主作答任务 | 未作答前的个人能力结论 |
| 题目要求 + 作答，缺材料 | 转写、形式要求、字数、结构和表达反馈 | 要点覆盖、材料依据和可靠分数区间 |
| 仅作答图片 | OCR、用户修订、文本结构和表达观察 | 是否答到要点、题型匹配和分数 |
| 部分材料或截图 | 原题候选和缺页提示 | 直接生成标准答案 |

申论原题搜索可使用题目要求、材料特征句、年份/地区和图像指纹混合召回。用户确认原题前，AI 不得将某一候选的参考要点带入评阅。

## 6. 证据和行为权重

| 行为 | 是否记录 | 是否影响能力 | 是否影响计划 |
|---|---:|---:|---:|
| 查看/打印/导出 | 是 | 否 | 仅用于任务可达性，不计完成 |
| 拍题或搜索 | 是 | 否 | 可产生待处理任务 |
| 确认题目与原答案 | 是 | 有条件 | 是，但使用外部证据权重 |
| 程序内限时作答 | 是 | 是 | 是 |
| 纸上作答 + 整卷自报用时 | 是 | 是，时间维度降权 | 是 |
| 未确认 OCR 或相似匹配 | 是 | 否 | 否 |
| 只看解析未作答 | 是 | 否 | 可安排后续验证，不标掌握 |

证据等级由确定性代码按来源、完整度、可验证性和时间条件计算，不交给大模型自由决定。

## 7. 付费边界

付费购买的是**更深的个人化计算、持续记忆、批量处理和动态规划**，不是购买自己的数据、标准答案或虚假确定性。

### 7.1 永久不应收费的能力

- 账户、隐私同意、数据查看/导出/删除和订单查询。
- 手工录入自己的答案、成绩、复盘和申论文本。
- 查看自己已产生的作答、原始表达、修订历史和已购买结果。
- 确认/否定 OCR、原题匹配、错因候选和内容争议。
- 用户自有数据的标准导出。

### 7.2 免费层用于证明价值

- 资格建档、岗位筛选和有限的目标分证据。
- 标准组卷和单份基础学习包导出。
- 每周一定数量的拍题精确匹配和基础存量解析。
- 有限的 AI 解题、错因复盘、申论评阅和计划刷新；数量和服务级别在使用前明示。

### 7.3 付费层的主价值

- 按个人计划、错因和复测到期日自动生成智能纸笔包，支持批量导出与回流。
- 批量 OCR、自动分题、图形混合搜索、外部错题归档和重复检测。
- 深度解题追问、错因确认、变式/延时验证和长期错误模式。
- 申论完整材料评阅、重写对比和迁移验证。
- 持续能力估计、岗位分差、每日/每周动态计划和长期学习记忆。

### 7.4 计费原则

- 后端 `commerce` 是商品、订单、权益、额度、预留、确认和返还的唯一 owner；微信支付和后续 App 内购只是支付渠道。
- 先校验权益并预留额度，处理成功后确认消耗，失败或不可用结果必须自动返还。
- 同一份上传重试、轮询和查看已生成结果不重复计费。
- 额度用尽时明确告知可用时间、剩余数量和购买选项，禁止静默换成低质量模型。
- 所有额度数字必须由真实模型、OCR、存储、带宽和支付成本压测后配置，不在客户端硬编码。

## 8. 界面入口

- **今日**：每个任务提供“在小程序完成”和“纸笔/笔记 App 完成”执行方式，两者回到同一复盘。
- **训练**：固定入口为“智能组卷”、“拍题/导入”、“录入答案”和“待复盘”。
- **拍题结果**：先显示原图、识别状态和匹配差异，再显示解析；“记入错题”必须先询问原答案和当时思路。
- **申论**：允许选择“搜原题”、“上传完整作答”和“仅转写手写稿”，不用一个按钮混合三种承诺。
- **学习档案**：显示外部证据数量、待确认识别、证据等级和对计划的实际影响。

## 9. 实施门禁

- 打印包的题号、题目版本、答题卡和回流任务在整条链路一致。
- 任何外部内容在用户确认前不影响能力、错因和规划。
- 图推测试集覆盖旋转、叠加、数量、局部差异、分类和低质量拍摄。
- 申论缺材料时技术上禁止生成要点覆盖率和可靠分数。
- 外部截图不会被静默收录为公共题库、训练数据或跨用户搜索结果。
- 权益返回预估消耗、实际消耗、剩余额度、刷新时间和服务级别。
- 用户可以完整导出自己的原始证据、识别修订、作答和复盘，不受会员到期影响。
