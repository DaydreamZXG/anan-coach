# 学习优先纠偏 — 对前稿的修正（治国 Gamification）

> 触发：用户指出"这是服务于刷题学习的，是否偏了"
> 结论：前稿（尤其封地系统）有把游戏化做成独立目标的倾向，须以"学习效能"为唯一验收标准重审。
> 作者：GameDesigner ｜ 日期：2026-07-07 ｜ 版本：v0.1

## 1. 我偏在哪

我把"上头 / 留存"当成了目标本身，而它只是手段。具体偏了三处：

1. **封地成了平行游戏**：6 辖区升级 + 建筑意象，本质是给能力条套了一层养成外衣。若它自带"长得漂亮"的奖励感，玩家会为养封地而练，而非为补弱点而练——游戏抢了学习的注意力。
2. **投资留存放错了情绪**：我主张用"舍不得封地"取代"怕掉级"。但学习者真正该被唤醒的是**考试倒计时与剩余分差**的适度紧迫感，不是对虚拟封地的感情。全正能量会消解必要的紧迫。
3. **agency 与学习最优路径冲突**：我欢呼"让玩家选练哪片辖区"，但学习最优几乎总是"练最弱项"。给太多自由 = 允许逃避弱项，恰好和原方案"熔断"想阻止的事相反。

## 2. 铁律（此后所有机制的唯一验收标准）

> 一个游戏机制只有当它**增加用户练习"该练的题"的频率或质量**时，才值得保留。
> 凡把注意力从"正确学习行为"引向"游戏内奖励"的机制，一律砍或重定向。

验收三问：
- 它让用户更多练**弱项 / 真题**了吗？
- 它让一次练习的**吸收质量**更高了吗（而非更快 / 更多无关题）？
- 它有没有用 extrinsic bribe 替代了"离上岸更近"这个本应最强的内在奖励？

## 3. 用铁律重审六大杠杆

| 杠杆 | 重审结论 | 修正 |
|------|---------|------|
| ① 分差英雄指标 | ✅ 通过 | 保留，且必须是最显眼的数字 |
| ② 封地成长 | ⚠️ 风险 | 繁荣度增长**严格绑定"练了弱项"**，不绑定"任意练习"；封地只是 mastery 的可视化仪表，不发放独立奖励 |
| ③ 投资留存 | ⚠️ 修正 | 保留无惩罚；但归来触发必须指向"距考试 N 天 / 分差还剩 X"，而非"封地想你" |
| ④ 会话钩子 | ⚠️ 修正 | 钩子指向"下一步该练什么"（如"数量关系最弱，已备好 3 题"），删除 cosmetic 解锁 bribe |
| ⑤ 可见变强 | ✅ 通过 | 但展示须基于真实能力曲线，禁止注水 |
| ⑥ 社会性证明 | ✅ 通过 | 避免炫耀式排名引发焦虑或刷分；突出"你比同分段更稳" |

## 4. 三个具体机制修正

### 4.1 封地：从"养成游戏"降级为"学习仪表"
- 封地不再有独立奖励经济；它的繁荣度**只在你当日 / 本周练了最弱项时上涨**，练舒适区不涨（或微涨）。
- 这样游戏奖励与学习最优行为**重合**，而不是竞争。
- 建筑意象仅作能力条的美化，不提供任何 gameplay 增益。

### 4.2 连击：从"速度连击"改为"攻坚连击"
- 原连击奖励速度，会诱发抢答、牺牲正确率。
- 改为：**在弱项模块或高难题上连续做对**才给连击 / 水墨火焰。奖励"啃硬骨头"，对齐学习。

### 4.3 熔断：收回"可一键忽略"
- 弱项胜率长期不练会退化；完全可忽略的软推荐太弱。
- 改为：**强推荐 + 轻量引导**——今日政务默认把弱项排在最前，玩家可手动跳过但需一次确认（制造"我明知该练却跳过"的轻微认知摩擦，而非强制锁库）。

## 5. 给工程 / 产品的验收清单
- [ ] 任一游戏机制上线前，须能回答铁律三问
- [ ] 封地增长日志可追溯到"具体练了哪个弱项"
- [ ] 不存在"为拿游戏奖励而练无关题"的路径
- [ ] 归来推送含考试倒计时与剩余分差
- [ ] 连击 / 火焰触发条件绑定弱项或难题
- [ ] 主 KPI 是分差缩小速率 / 模考提升 / 上岸率，不是 DAU 或时长本身
