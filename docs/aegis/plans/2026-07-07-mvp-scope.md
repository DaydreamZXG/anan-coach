# 治国 App — 最小 MVP 范围

> 状态：app 未发布，核心为雏形待打磨。本文件定义"能验证假设的最小版本"。
> 作者：GameDesigner ｜ 日期：2026-07-07 ｜ v0.1

## 一句话目标
在已有后端核心上，做最小 iOS App，验证假设：**"看得见分差缩小 + 低负担回归"能让用户比裸刷题更坚持**；同时用轻量"治国"皮肤测世界观是否讨喜。

## 要证的假设
- **H1（留存）**：分差进度条 + 明日政务预告 + 归来提醒 → 7 日留存高于裸刷题对照组。
- **H2（世界观）**：轻量治国皮肤（术语 + 盖章 + 幕僚模板话术）→ 用户定性反馈"有意思 / 想再用"。

## MVP 闭环（必须跑通）
- **时刻**：翻开今日政务 → 答题 → 盖章(准/驳) + 简解析 → 分差 / 今日进度刷新
- **会话**：完成今日政务(约 N 题) → 看到今日治绩 → 明日政务预告（钩子）
- **长期**：分差持续缩小 → 轻量品级升迁动画 → 模考校准分差

## 范围 IN
**复用核心（不重建）**：选岗→目标分 ｜ 摸底→预估分→分差 ｜ 加权抽题→今日政务 ｜ 答题反馈 ｜ 错题 AI 解析 ｜ 6 板块切换
**L1 进度可见**：顶部治绩栏（分差进度为英雄指标）｜ 每次练习 / 模考后分差更新 ｜ 明日政务预告 ｜ 归来推送（考试倒计时 + 剩余分差）
**轻 L2 治国皮肤**：术语映射 ｜ 盖章反馈(准/驳) ｜ 轻量品级徽章 + 升迁动画 ｜ 幕僚少量模板话术

## 范围 OUT（明确砍，留给后续验证后再加）
封地 / 辖区 ｜ 民心 / 精力值 ｜ 御史台惩罚 ｜ 排行榜 ｜ 变现 / 订阅 / 锦囊 ｜ 多套 UI 主题 ｜ AI 幕僚全套话术 ｜ 上帝视角 / 怪题焚毁 / 申论 Boss

## 依赖核心的接口（数据契约，现在留）
分差 = 目标分 − 预估分 ｜ 各模块滚动胜率 ｜ 连续学习天数 ｜ 单次练习质量

## 成功标准（先于开发定义）
- 完整闭环可跑：选岗 → 摸底 → 定目标 → 每日刷 → 看到分差变
- 7 日留存 > [基线，需先测裸刷题基线]
- 定性：用户能说出"我在靠近上岸""想再用"
- 内测 30–50 人，2–3 周

## 防蔓延清单（不做）
不做完整世界观叙事（只轻皮肤）｜ 不做养成 / 经济系统 ｜ 不做社交 ｜ 不做付费

## ⚠️ 一个必须你确认的假设
我假设**后端核心（题库 / 抽题 / 岗位进面分 / AI 解析 / 模考）按接手文档是已存在、可复用**的资产。
- 若是 → MVP = iOS App + L1 + 轻皮肤，范围如上。
- 若否（核心也只是计划）→ MVP 要先建核心，工作量翻倍，本范围需重写。
