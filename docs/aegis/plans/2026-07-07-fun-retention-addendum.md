# 治国 Gamification — 吸引力与上头强化设计（接手补强建议）

> 配套：2026-07-06-governance-gamification-master-plan.md
> 视角：GameDesigner，聚焦"可不可行 + 怎么上头"
> 日期：2026-07-07

## 一、可行性 verdict（先给结论）

技术可行（架构复用到位，无硬伤）。但**"上头"只成功一半**：

- 作为"激活钩子"完全可行——古风权力幻想 + 盖章反馈 + 晋升金光，能在前 2–3 周拉起新颖度与首日/次日留存。
- 作为"长期留存引擎"有风险——方案里大半系统（民心衰减、御史台降级、精力上限、熔断硬锁）是**惩罚型留存**，而目标用户是本来就被考试压得喘不过气的考生。novelty 退潮后，这些系统会从"好玩"变成"第二份差事 / 焦虑源"，反而推高流失。

一句话：**这是一层"动机皮肤"，还不是一台"乐趣引擎"。** 上头潜力是真实的，但被埋在惩罚逻辑下面。

## 二、核心判断：皮肤 vs 引擎

游戏让人上头的本质不是"加了 XP 和排行榜"，而是**玩家在每一步都做着有意义的选择，并持续看到自己变强**。

当前方案的结构是：系统安排你做模块 X（今日政务 / 熔断）→ 你执行 → 拿到抽象奖励（XP / 品级）。玩家是**执行者**，不是**决策者**。缺的是 agency（主动权）和 competence（可见的成长感）——而这两样，恰恰是学习类产品最长效的多巴胺来源。

## 三、让它能上头的 6 个杠杆

### 杠杆①：把"分差"立为英雄指标（最重要）

- **原理**：对考生，最 compelling 的数字不是 XP，而是"距上岸还差多少分"。它 1:1 映射真实目标，是有意义数字，不是任意数字。
- **落地**：顶部状态栏把"分差"做成主视觉（如一道在收缩的进度条），每次模考 / 练习后立刻显示"分差 -2.3 分"。XP / 品级退为副指标。
- **为什么上头**：缩小分差是**可感知的、指向人生目标的进展**，比任何虚拟品级都黏人。

### 杠杆②：用"成长型封地"替代"衰减型民心"

- **原理**：损失厌恶要用对——让人"舍不得丢掉自己建起来的东西"，而不是"怕被惩罚"。
- **落地**：把民心换成**治下封地 / 辖区**：随持续、高质量学习而**生长**（县→府→道，辖区繁荣度上涨、人口增加）。断更只是**暂停生长**，不痛苦缩水。
- **为什么上头**：这是星露谷农场隐喻的精髓——你守护的是自己养大的东西，不是躲惩罚。情绪是骄傲，不是焦虑。

### 杠杆③：惩罚留存 → 投资留存

- **原理**：streak / 连续天数一旦用来"惩罚中断"就变成负向压力；一旦用来"你已经投入这么多，别断"就是正的 sunk-cost。
- **落地**：御史台从"48h 不答就降级"翻转为"你已连续理政 18 天，封地初成——今日政务已备好，来盖个章？" 中断有宽限期且**不影响已有成果**。
- **配套**：熔断从硬锁库改为**软推荐**（"该模块已达 85% 胜率，建议转攻弱项 数量关系，可一键忽略"），把选择权交还玩家。

### 杠杆④：会话结束钩子（"再来"触发器）

- **原理**：星露谷的"再玩一天"来自每个会话结尾埋的期待。
- **落地**：每次退出时显示"距今日治绩目标还差 3 题"或"再答 5 题可解锁明日政务预览 / 一份幕僚密折"。给一个**微小、可达的下一步**。
- **为什么上头**：把"今天到此为止"变成"就差一点"——这是最高频的"上头"时刻。

### 杠杆⑤：让"变强"可见（最长效多巴胺）

- **原理**：学习类产品真正的爽点是"我以前总错，现在会了"。
- **落地**：6 板块能力条从被动展示升级为**周度成长回顾**（"推理胜率 55%→72%，本周超越 63% 同榜"）+ 答对瞬间幕僚点出"此消彼长，你已通此道"。
- **为什么上头**：把抽象的"做对题"翻译成"我在变强"，可持续数月不腻。

### 杠杆⑥：社会性证明，而非社会性羞辱

- **原理**：对高压考生，raw 排行榜会击垮低分者；但"我超过了谁 / 我和同分段谁更稳"是 safe 的正向社交。
- **落地**：同榜进士榜按**分差缩小速度**或**稳定度**排，并突出"你超越了 X 位同榜""你比同分段 70% 人更稳"，而非裸分排名。
- **为什么上头**：社交比较保留竞争快感，去掉毒性。

## 四、要砍 / 要翻的转换清单

| 当前设计 | 问题 | 改法 |
|---------|------|------|
| 民心衰减 + <30 暗红羞辱 | 焦虑源，未列风险 | → 成长型封地（只长不痛缩） |
| 御史台降级惩罚 | 惩罚型留存 | → 投资型提醒（守护已有成果） |
| 精力值上限 | 与目标（多刷）反向 | → 砍掉，或改为满精力加成 buff |
| 熔断硬锁库 3 天 | 剥夺 agency | → 软推荐 + 可一键忽略 |
| 排行榜按 XP 裸排 | 毒性比较 | → 按分差缩小 / 稳定度 + 超越提示 |
| 锦囊"保命"付费避罚 | 伦理 + 合规风险 | → 正向增益（提示 / 跳怪题 / 深解） |
| XP 与分差双引擎 | 进度叙事断裂 | → 分差为主引擎，XP 降为反馈奖励 |

## 五、伦理与合规红线（必须守）

- **不做开箱 / 抽卡式变量奖励**：教育产品 + 国内盲盒 / 未成年人消费监管，lootbox 式随机掉落是雷区。变量奖励只放在**内容本身**（终于破解的怪题、幕僚惊喜技巧、超越同榜），不放在随机掉落。
- **不做付费避罚**：锦囊改为正向增益，绝不做"花钱别降级"。
- **留存靠投资不靠胁迫**：所有"回来"的触发应让人因"舍不得成果"而回，不因"怕掉级"而回。
