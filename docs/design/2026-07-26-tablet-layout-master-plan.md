# 平板排版总纲（2026-07-26 初稿，待产品拍板）

## 1. 三断点分工（已实现，不再变）

| 断点 | 形态 | 机制 |
| --- | --- | --- |
| <768px | 手机原样 | rpx 等比，底部通栏 Tab |
| 768–1023px | 单列限宽 + 悬浮胶囊 Tab | `--rpx: 0.5px` 去放大；`.page`/`.s9-*` 全局限宽居中 |
| ≥1024px | 多栏增强 | 在 768 基础上叠加各页面模板 |

尺寸只经 `calc(N * var(--rpx))` 与 token；禁止新增裸 rpx/px（validate-tokens 拦截）。

## 2. 五类页面模板（≥1024px）

1. **主 Tab 页**：主列 minmax(0,1fr) + 辅列 340px，header 满宽（今日已实现；能力/我的为双卡变体）
2. **做题页**：材料 minmax(340px,0.95fr) | 题目 minmax(0,1.2fr)，粉笔式轻量选项行（已实现）。待做：材料题组连续滚动、可拖分栏把手
3. **列表页**（学习包/私人资料/报告中心/学习圈）：卡片 2 列网格 `repeat(2, minmax(0,1fr))`，gap 20px，页宽 1100px（待批量套用）
4. **表单/向导页**（onboarding、资格、偏好）：保持单列 readable-max 720px 居中，不做多栏（表单多栏伤完成率）
5. **报告/详情页**：正文列 minmax(0,1fr) + 指标侧栏 320px；无侧栏内容则单列 860px（待套用）

## 3. 密度与留白规则

- 卡片内距统一 16–20px（平板值），区块间距 20–24px，列 gap 20–24px
- 每屏信息密度目标：列表 ≥6 卡、做题右栏 ≥1.5 题、主 Tab 无整屏空白
- 悬浮胶囊 Tab 底部让位 88px；触控 44px 底线不因密度收紧而破

## 4. 实施顺序（拍板后）

1. 列表页模板批量套用（约 8 页，机械）
2. 报告/详情页模板（约 6 页）
3. 材料题组连续滚动（controller 级，独立一轮）
4. 可拖分栏把手 + 题头内联工具行
5. iPad 认证机型进视觉流水线（平板防回归基线）
