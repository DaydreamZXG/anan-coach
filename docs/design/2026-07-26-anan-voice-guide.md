# 岸岸声音指南（2026-07-26 定稿）

在 ui-copy-style-guide 的合规底线之上，这份指南定「性格」。
说明书告诉用户发生了什么；岸岸陪用户走过正在发生的事。

## 性格三条

1. **站在用户这边，不站在系统那边。** 主语尽量是「你」的进展，不是「系统」的动作。
   坏：「档案已生成，推荐可信度：较高」／好：「你的备考档案立起来了，接下来的推荐都有出处」
2. **克制的笃定。** 不喊加油、不画饼、不承诺上岸；把确定的事说满，把不确定的事说清。
   坏：「继续努力，胜利在望！」／好：「这 45 分钟的证据已经记进你的能力档案」
3. **在场感。** 关键时刻说此刻的话，不说任何时刻都成立的话。
   坏：「操作成功」／好：「交卷了。先深呼吸，成绩不会跑」

## 分场景语气档

| 场景 | 语气 | 忌 |
| --- | --- | --- |
| 开场/引导 | 邀请，给理由 | 命令式「请完成…」 |
| 进行中 | 安静陪跑，少打扰 | 弹夸奖 |
| 完成/结算 | 认可具体的事实 | 空洞庆祝 |
| 挫败（错题/低分） | 把失败翻译成信息 | 安慰话术、贬低题目 |
| 等待/加载 | 说正在为你做什么 | 「加载中…」 |
| 出错/缺数据 | 认账+给下一步 | 技术词、甩锅网络 |

## 例句库（可直接引用的骨架）

- 空态：「这里还空着，因为____。先去____，回来就有了。」
- 完成：「____已经记下了。它会体现在____。」
- 错题：「这道题暴露的是____，比做对十道更值钱。」
- 等待 AI：「岸岸在核对你的____，不编没有依据的话。」
- 风险提示：「这一步会____，做之前想清楚就行。」

## 执行纪律

- 单句 ≤30 字优先；两句封顶；数字/事实置前。
- 「岸岸」自称仅在 AI 主动行为处出现；系统性动作不拟人。
- 全部文案过规范 §6（无工程词、Request ID 保留）。

## 深度三律（2026-07-27 增补，用于情绪关键时刻）

超出日常提示的「深文案」只出现在情绪节点（开屏、暂停、错题、交卷、结算、
二战起点），全应用同时存在的深文案 ≤10 句，多则廉价。

1. **具象胜过抽象。** 写题、分、天数、那道错过的题；不写梦想、坚持、未来。
2. **转折出深度。** 一句之内完成一次视角翻转（十四行诗的 volta）：
   前半句陈述常识，后半句把它掀开。
   例：「错题不欠你道歉，它欠你一个答案。」
3. **静水流深。** 不用感叹号，不用省略号卖惨；深度用陈述句说完就走。

反例（禁止）：「相信自己，你一定可以！」「星光不问赶路人」。
基准（已在库）：「别把去年会的内容再学一遍」「今天到这里，看看真正留下了什么」。

新增/替换深文案必须先从此表挤掉一句；基座语气按前述三性格铺满全站。

## 离别句·唯一例外位（2026-07-27）

删除账户确认区末行：「祝你上岸——无论哪一边的岸。」
不占十句预算：它只对决定离开的人说一次。产品价值观：放弃也是一种上岸，
但这句话只允许出现在用户自己走向门口之后，任何低谷时刻不得弹出劝退。
