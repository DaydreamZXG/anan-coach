# 岸岸角色资产发布 v1.0

> 发布状态：角色设计、独立资产包和微信小程序主产品回接均已完成。

## 已冻结

- 奶牛猫、小肥但灵活、暖金眼、灰项圈与青色坐标灯。
- 不对称深海军蓝/暖白花纹与最终阶段比例。
- 主动、好奇、有点憨、偶尔小吐舌的动作性格。
- 四阶段不可倒退成长；不以喂食、XP、付费或连续打卡驱动。
- 六种伴随语义、尺寸层级、动效边界和无障碍策略。

## 交付包

- 微信小程序：`production/miniprogram-v1/`
- Codex v2：`production/codex-v2/package/`
- Codex 完整 QA：`production/codex-v2/run-20260714/qa/`
- 回接指南：`specs/anan-integration-guide-v1.md`
- 发布验收：`qa/release-validation.json`；可用 `python3 tools/validate_release.py` 重跑。

## QA 结论

- 小程序静态：35 项，alpha/键色校验通过。
- 小程序动画：6 条，240×240 单元，帧数、边界、键色、透明 RGB 与单条包体预算全部通过。
- Codex v2：8×11 图集、16 方向、三方盲测和最终视觉 QA 通过；已记录两个次要方向连续性警告。
- 全包验收：路径、尺寸、体积、SHA-256 与两端 QA 引用均通过。

## 主产品接入

- 微信小程序统一视觉组件已替换原蓝紫色 CSS 占位形象。
- 主包只携带 266,874 bytes 核心资源，其余五种意图动画及成长大图按语义异步分包。
- 业务页面不引用具体资源；运行时清单、动画帧率、播放策略、减少动效和无障碍名称均有自动验收。
- Codex v2 继续独立安装，不被小程序读取。

## 仍不属于本发布

- 角色音效或拟人配音。
- 商业换装、喂养、抽取或成长付费机制。
- 方法卡社区自由文字评价。
