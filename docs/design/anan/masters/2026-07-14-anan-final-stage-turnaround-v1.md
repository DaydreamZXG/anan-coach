# 岸岸最终阶段四视图 v1

## 状态

- 状态：冻结为角色身份母版 v1。
- 用途：所有静态动作、成长阶段和动画资产的身份参考。
- 不直接作为小程序运行时图片或 Codex 图集输入。

## 身份锁定

- 成年健康的小肥猫体态：胸腹圆，四肢仍具备跑、跳、扑的长度与受力结构。
- 暖白底色、深海军蓝奶牛花纹；禁止生成纯黑高反差塑料质感。
- 暖金色眼睛、粉鼻、短吻、直立三角耳。
- 角色左脸深色帽斑下探更深；角色右脸白颊面积更大；额心为不规则窄白焰。
- 上背一块深色鞍斑；角色左后胯圆斑；角色右中腹纵斑；深色尾巴，根部保留暖白环。
- 软灰项圈；正中为低亮度青色圆角矩形坐标灯。

## 比例

- 站姿总高：5.0 个爪掌高度。
- 头宽约为肩高的 0.70；头高约占总高 0.30。
- 躯干最大宽度约为头宽的 1.18；不得超过 1.28。
- 前爪可读宽度约为眼睛直径的 1.10。
- 尾根粗、尾尖圆；自然下垂时不得遮挡主要背部花纹。

## 表现边界

- 允许腹部在跳跃、翻身与趴卧动作中产生明显弹性变形。
- 不把体型演成行动困难、喘息或需要减肥。
- 吐舌是偶发强调：舌尖露出不超过鼻宽的 45%，不可成为默认表情。
- 28–36 px 使用脸部简化版，不强制显示项圈灯。
