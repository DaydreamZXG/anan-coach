# 岸岸生产资产合同 v1

> 角色母版共享，微信小程序与 Codex 桌宠分别建模、分别验收。

## 1. 权威来源

1. 角色身份：`masters/2026-07-14-anan-final-stage-turnaround-v1.*`
2. 角色规则：`anan-character-system-v0.1.md`
3. 语义和动作：本文件。
4. 运行时映射：`production/miniprogram-v1/manifest.json` 或 Codex `pet.json`。

若视觉稿与语义合同冲突，以语义合同为准；若派生资产的花纹、比例与母版冲突，以母版为准。

## 2. 小程序资产合同

### 2.1 运行时语义

| CompanionIntent | 默认动作 | 静态关键帧 | 可循环 |
|---|---|---|---|
| companion | 歪头抬爪、尾尖轻摆 | `companion` | 是 |
| thinking | 低身追踪、耳朵分向 | `thinking` | 是 |
| reminder | 坐直并伸爪轻拍 | `reminder` | 否 |
| encouragement | 双爪小跳、落地回弹 | `encouragement` | 否 |
| rest | 猫饼慢眨或翻肚皮 | `rest` | 是 |
| deprioritize | 靠近、收笑、稳定直视 | `deprioritize` | 否 |

业务层只传 `CompanionIntent`、成长阶段和动效偏好，不直接指定帧号、文件名或文案。

### 2.2 尺寸层级

- `avatar-32`：32×32 CSS px；脸部图标，2x/3x 输出。
- `inline-64`：64×64 CSS px；半身单动作，2x 输出。
- `card-160`：160×160 CSS px；全身动作，2x 输出。
- `hero-240`：240×240 CSS px；角色介绍与成长回顾，2x 输出，按需加载。

图片源文件保持透明背景、sRGB、直边 alpha；运行时优先 WebP，无损 PNG 只作母版与兼容源。不得把文本、气泡、状态图标烘焙进角色图。

### 2.3 动画

- 常驻循环：6–12 fps；单次强调：12–18 fps。
- 陪伴循环 2.4–4.0 秒；思考循环 1.6–2.4 秒；休息循环 4.0–6.0 秒。
- 单个循环图集目标不超过 220 KiB；首页首屏岸岸相关资源合计目标不超过 350 KiB。
- `prefers-reduced-motion` 或小程序动效关闭时，使用专门静态关键帧；不是抽取随机首帧。
- 动画不得显示虚假进度，不得在用户阅读题干时持续抢动。

### 2.4 成长

四阶段共享同一语义动作接口；成长只改变体型成熟度、姿态开放度和坐标灯，不改变功能权限。阶段不可回退，不由付费、刷题量或连续打卡直接驱动。

## 3. Codex v2 桌宠合同

- 固定为 1536×2288 WebP，8 列×11 行，单元格 192×208，`spriteVersionNumber: 2`。
- 0–8 行遵循 Codex 标准动作；9–10 行提供 16 个每 22.5° 一档的观察方向。
- Codex 桌宠固定使用最终阶段形象，不在图集中编码小程序四阶段成长。
- 所有语义、连续性、方向盲测和图集结构 QA 独立完成；通过后再打包。

## 4. 无障碍

- 可访问名称描述当前意图，例如“岸岸正在思考你的计划”，不使用“可爱猫咪”作为唯一信息。
- 错误、风险、付费、隐私与网络状态必须保留独立图标和文本；岸岸不得替代。
- 颜色不是唯一语义通道；必须同时依赖轮廓、姿态、目光和节奏。

## 5. 版本与变更

- 身份或花纹变化：主版本升级。
- 新动作或新尺寸：次版本升级。
- 压缩、裁切和不改变视觉语义的修复：补丁版本升级。
- 禁止覆盖历史母版；资产清单记录 SHA-256、尺寸、色彩空间和来源。
