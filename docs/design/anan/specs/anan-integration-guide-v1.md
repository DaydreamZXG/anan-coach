# 岸岸回接主产品指南 v1

## 1. 接入边界

回接层只接收语义化请求，不允许业务页面引用具体图片名、帧号或 Codex 行号。

```ts
type CompanionVisualRequest = {
  intent: 'companion' | 'thinking' | 'reminder' | 'encouragement' | 'rest' | 'deprioritize'
  visualStage: 'stage-1' | 'stage-2' | 'stage-3' | 'stage-4'
  size: 'avatar-32' | 'inline-64' | 'animated-120' | 'card-160' | 'hero-240'
  motion: 'allowed' | 'reduced'
  context: 'home' | 'plan' | 'question-reading' | 'post-submit' | 'review' | 'report' | 'emotion' | 'empty'
}
```

业务域继续使用既有 `CompanionIntent`。视觉适配器读取 `production/miniprogram-v1/runtime-manifest.json` 决定静态图、动画图集、帧率和可访问名称。

## 2. 选择规则

1. `avatar-32` 永远使用专用头像，不从全身图缩放。
2. `motion = reduced` 时使用该意图的静态关键帧。
3. `question-reading` 只允许头像或静态小图；提交、暂停、超时和复盘后才允许动画。
4. 连续动画不超过 120 CSS px；160–240 px 使用高分辨率静态图或单次强调动画。
5. 成长阶段只替换成长展示与中性形象，不改变功能权限、语义动作或业务状态。

## 3. 场景频率

| 场景 | 允许尺寸 | 动效 |
|---|---|---|
| 首页 | 64–120 | 陪伴循环；一次进入只自动播放一次完整招呼 |
| 学习计划 | 64–120 | 思考循环；产出后切换复核/陪伴静态帧 |
| 题目阅读 | 32–64 | 静态，不持续运动 |
| 提交后复盘 | 64–120 | 鼓励、提醒或降权建议单次播放 |
| 报告 | 64–160 | 默认静态；关键结论只播放一次 |
| 情绪支持/恢复日 | 120–160 | 休息低频循环或静态猫饼 |
| 空状态 | 120–160 | 陪伴静态或一次招呼 |
| 全局问答 | 32–72 | 头像/半身静态；思考时按需动画 |

## 4. 分包与缓存

- 主包：头像、陪伴 64/160 静态图、陪伴动画，合计 266,874 bytes。
- 成长分包：四阶段 480 px 资产，仅角色介绍、成长回顾或首次阶段变化时加载。
- 意图动画：按意图单独加载，单条均小于 220 KiB；完成后可按版本哈希长期缓存。
- 资源 URL 必须带 `releaseVersion` 或内容哈希；不得覆盖旧文件名造成客户端缓存污染。

## 5. 无障碍

- 使用 `runtime-manifest.json` 中的 `accessibleLabel`，不要统一写成“可爱猫咪”。
- 岸岸语义必须同时依赖目光、耳朵、姿态和轮廓；颜色只作辅助。
- 减少动效是完整模式，不得丢失提醒、风险说明或操作入口。

## 6. 验收清单

- 页面只传语义请求，不出现硬编码帧号。
- 六种意图在静态和动效关闭状态下均可辨认。
- 题目阅读首屏无大形象和持续循环。
- 主包岸岸资源不超过 350 KiB。
- 动画单条不超过 220 KiB，无裁切、碎片、洋红边和透明 RGB 残留。
- 错误、风险、支付、隐私和网络状态仍有独立图标与文字。
- 方法卡社区只允许投票/结构化反馈，不新增自由文字评价。

## 7. Codex 资产隔离

Codex v2 包位于 `production/codex-v2/package/`，使用 1536×2288、8×11、192×208 单元格。它只共享岸岸身份母版，不得被小程序运行时直接读取。
