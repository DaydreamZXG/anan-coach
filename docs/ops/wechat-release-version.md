## 发布规则

1. 上传前同时核对微信后台正式版和本文件中的最新有效体验版。
2. 新上传版本必须高于两者中的最大版本；当前下一版本不得低于 `0.1.25`。
3. 微信开发者工具返回成功后，才可以更新“最新有效体验版”。
4. `0.1.13` 和 `0.1.16` 是 2026-08-09 误传的低版本体验记录，不得用于提审；`0.1.19` 含已修复的静默入口阻断，也不得重新提审。
