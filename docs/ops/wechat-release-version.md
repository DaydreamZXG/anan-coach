1. 上传前同时核对微信后台正式版和本文件中的最新有效体验版。
2. 新上传版本必须高于两者中的最大版本；当前下一版本不得低于 `0.1.22`。
3. 微信开发者工具返回成功后，才可以更新“最新有效体验版”。
