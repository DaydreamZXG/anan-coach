# 岸岸微信小程序 · 前端设计与实现规范

> 四个主 Tab 的视觉唯一依据是 Figma Design File
> `pU5sxRfG4UFeCCrnSPoaAX`（今日 `3:2`、能力 `4:2`、岸岸 `6:2`、我的 `7:2`）。
> Figma Make / Antigravity 只提供交互意图，不能覆盖真实 controller、接口、路由与数据状态。
> 产品边界以 `docs/product/2026-07-18-canonical-product-boundaries.md` 为准。

## 1. 产品界面原则

1. 岸岸是“以国考目标岗位为终点的 AI 学习教练”，主链必须能从建档、定岗一路走到任务、复盘、能力更新和计划调整。
2. 没有数据就说明还缺什么，并给出真实下一步；禁止演示数据、假成功、内存成功和“稍后开放”死入口。
3. 写给考生看，不把接口名、枚举、规则版本、指纹、事务、回执、投影等工程概念直接放到界面。
4. 重要结论要同时说清依据和边界：岗位分差不是录取概率，AI 判断可以被用户确认或否定，私人资料不跨用户复用。
5. 一个能力只有一个正式页面和一条正式数据链路。不能为了换皮复制出第二套岗位、通知、复盘或资料页面。

## 2. 视觉方向

- 页面使用石墨黑文字、极浅冷灰背景和大面积白色卡片，保留充足留白。
- 普通主操作使用石墨黑；靛蓝、紫色与玫红渐变只用于 AI 洞察、岸岸能力和智能状态。
- 不再使用旧版蓝青主色和暖橙陪伴色。成功、提醒、危险各自使用独立语义色。
- 卡片使用 24–32px 圆角与极轻阴影；层级来自间距、字号和明度，不堆叠描边与发光。
- 页面不得自行创造第二套颜色、圆角或阴影；先映射全局 token，再实现局部节点。

## 3. 导航与页面

- 固定四个 Tab：今日、能力、岸岸、我的。
- 岗位属于阶段性决策工具，从“我的”和建档结果进入，不占常驻 Tab。
- 路由唯一权威是 `miniprogram/app/navigation/routes.ts`，注册唯一权威是
  `miniprogram/app.json`；两者必须一致。
- 登录、建档和任务深链必须恢复原目的页，不能静默改跳到“差不多”的页面。
- 全局使用微信原生导航栏；确有自定义顶部导航的页面必须读取胶囊和安全区数据，不能只靠 CSS 猜高度。

## 4. 真实状态

页面按业务实际支持以下状态，而不是机械凑“四态”：

- 首次加载；
- 有数据；
- 无数据，并给出可执行下一步；
- 请求失败，展示安全的人话提示和 Request ID；
- 写入处理中；
- 版本冲突；
- 网络结果不确定时恢复原操作；
- 数据过期或部分可用。

读取失败不能改用演示数据；写入失败不能提示成功。短暂断网只保留已经真实取得的题面、答案和草稿。

## 5. API 与状态所有权

- 所有业务请求经 `miniprogram/api/client.ts` 和对应领域 API 类发出。
- OpenAPI 生成类型来自 `miniprogram/api/generated/types.gen.ts`，页面不得手写另一套服务端响应结构。
- 写操作使用稳定的幂等键；结果不确定时重放同一命令，不能新建第二次写入。
- 登录状态唯一由 `miniprogram/auth/session.ts` 持有；用户数据必须按 learner ID 隔离。
- 页面只负责展示与交互，版本冲突、恢复、校验和业务转换放在对应 controller / feature 中。

## 6. 文案

- 遵守 `docs/design/2026-07-22-ui-copy-style-guide.md`。
- 标题先说用户要完成什么；说明文优先控制在 30 字以内。
- 空状态必须回答“现在为什么没有”和“接下来点哪里”。
- Request ID 可以展示；错误码、数据库字段、模型内部过程不展示。
- 不出现“服务端、断点、证据链、门禁、投影、原命令、输入指纹”等工程词。

## 7. 手机与平板

- `app.json` 保持 `resizable: true` 和自动方向。
- 手机完成完整功能；平板不是简单放大，长材料题、申论和整卷模考使用材料/题目/作答双栏。
- 表单、对话和普通详情页保持可读限宽；主内容与次内容在宽屏可并排。
- 横竖屏切换不能丢失题号、答案、草稿、计时和编辑权。

## 8. 交付要求

- 改造阶段允许批量完成页面后统一验收，不要求每改一页都跑完整套件。
- 合入前必须一次性完成类型检查、路由/交互覆盖、关键真实链路、运行时警告、视觉对照、手机和平板真机验收。
- 正式版本不得带 401/404、属性类型警告、废弃 API 警告、静态演示数据或未解释的审核警告。
- 上述 Design File 节点是主 Tab 的像素与布局依据；视觉同步不能覆盖 controller、接口、恢复逻辑和真实状态。
- Figma Make 中的 mock、`setTimeout`、空按钮和 placeholder 路由不得进入正式代码。

## 9. 当前延期入口

以下能力保留实现或配置，但在条件成熟前关闭用户入口：

- 收费商品、退款和微信虚拟支付；
- 用户可见的手动云备份；
- 正式客服工单；
- 事业单位独立产品；
- 岸岸宠物形象替换。
