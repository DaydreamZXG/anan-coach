# 微信云测 Minium 自定义测试

这套用例用于微信开发者工具的“云测 → 自定义测试 → Minium”。它连接真实上传版本和测试账号，覆盖：

- 今日页任务队列合并，避免同类训练重新渲染成十几张重复卡片；
- “开始第一项任务”与后续任务卡、相邻任务卡之间的间距；
- “开始/继续”按钮保持横排；
- “完整模考”与“记录今天”之间的间距；
- 手机、竖屏平板保持单列，1024px 以上横屏平板进入双栏；
- 日计划调整、行测复盘和通知设置三个分包路由可打开。

## 生成上传包

在 `apps/wechat` 目录执行：

```bash
npm run minitest:package
```

产物为 `minitest/dist/anan-minium-cloud-tests.zip`。ZIP 根目录直接包含测试文件，没有多套一层目录，符合微信云测的 Minium 用例包规范。

## 在云测中运行

1. 在微信开发者工具“云测”的 Minium 用例管理中上传上述 ZIP。
2. 新建 Minium 测试计划，选择要验证的小程序版本。
3. 配置一个已登录且已完成新手引导的测试账号，否则今日页会按产品逻辑跳回登录或引导页。
4. 至少运行三组设备：手机竖屏、平板竖屏、宽度不低于 1024px 的平板横屏。
5. 编译页面使用 `/pages/today/index`；分包路由由测试脚本自行 `reLaunch`。

设备旋转由云测计划控制，同一套断言会根据当前视口自动判断应该是单列还是双栏，不需要维护三份测试代码。
