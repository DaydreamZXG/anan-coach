# 考公搭子 iOS

Native SwiftUI app for iPhone and iPad.

First local build target:

```bash
xcodebuild build -project apps/ios/Gongkao/Gongkao.xcodeproj -scheme Gongkao -destination 'platform=iOS Simulator,name=iPhone 17'
xcodebuild build -project apps/ios/Gongkao/Gongkao.xcodeproj -scheme Gongkao -destination 'platform=iOS Simulator,name=iPad Pro 13-inch (M5)'
```
