## 2. 已收口的系统问题

### 2.1 顶部导航与微信胶囊

- `workbench-nav` 统一读取真实状态栏和菜单胶囊几何。
- 标题采用左右对称胶囊预留，避免标题视觉偏心。
- 返回、关闭、暂存等页面操作不再与系统胶囊争抢空间。
- 34 个自定义导航页面被明确归类为 `workbench-nav`、`task-shell` 或根页面安全区三种契约。
- 自动化会读取标题、返回键、右侧操作和微信胶囊的实际包围盒，发生重叠即失败。

### 2.2 原生按钮几何与文字居中

- 全局原生按钮重置补全宽度基线。
- 页面级圆钮、整卡按钮、主 CTA 和胶囊控件显式声明自身几何。
- 定高扁平控件统一使用垂直、水平居中原语。
- 新增静态门禁，后续新增定高按钮但未声明居中方式会直接阻断 `npm run check`。

### 2.3 设计状态与运行时验收

- 视觉场景扩展到 79 个真实页面状态。
- 45 个 Figma 交付状态均绑定语义选择器与关键控件几何，不再只凭“截图成功”判定通过。
- 截图前后校验路由、注入数据、关键正文、主操作和顶部安全区，避免骨架屏、空正文或错误相态被误记为成功。
- 桌面目录同时提供 79 张逐页原图、7 张联系表和机器可读 manifest。

## 3. 本次追加修复

### 3.1 建档入口 Logo 偏移

根因是白色标记容器只有固定尺寸，没有建立子元素居中布局。现已使用容器级 Flex 几何居中，紫色标志在运行时水平、垂直均居中。

证据：`a09-onboarding-entry.png`

### 3.2 今日结算指标卡空值

生产页面原本已从结算数据派生计划时长、实际时长、完成数和差值，但视觉验收场景遗漏了这些派生字段，导致截图只剩“原计划 / 实际学习 / 完成”三行标签。

现已补全语义一致的验收数据，指标卡按 Design File 显示：

- 原计划：2.5 小时
- 实际学习：2 小时
- 完成：2 / 3 项
- 差值：比计划少 30 分钟

生产 API 与结算计算逻辑未改动。

证据：`b04-daily-settlement-ready.png`

### 3.3 备考档案图标缺失

根因是五枚本地图标通过动态 `src` 绑定，微信构建器无法稳定把这些路径识别为静态包依赖。

现已改为 WXML 中按模块 key 分支引用五个字面量资源路径，并删除不再需要的 `iconSrc` 视图字段。运行时五枚图标均已显示。

证据：`f16-profile-archive-ready.png`

### 3.4 私人资料库伪 Tab

底部“资料库首页 / 上传与阅读 / 资料管理 / 辅导溯源”不是正式产品导航，而是生图阶段遗留的生产产物。

现已：

- 从资料库首页和详情页移除该组件；
- 删除 `libraryNavActive` 与 `navigateLibrarySection` 无用状态和事件；
- 删除整个 `library-nav` 组件；
- 保留真实深链 `?section=` 能力；
- 重新按安全区设置页面底部间距，避免删除固定导航后出现多余空白或内容贴底。

证据：`h04-private-knowledge-ready.png`、`h07-private-knowledge-detail-ready.png`
