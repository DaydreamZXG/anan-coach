# 图推双层契约

`dual-layer-contract-v1.json` 把同一题的结构拆成两个互相校验但职责不同的层：

- 可推理语义层：面板序列、元素身份与数量、位置、填充/纹理、文字、方向、部件、连接/包含/重叠关系、拓扑，以及跨面板旋转、翻转、平移、叠加、增减、置换等观察或候选关系。
- 可渲染图元层：只复用正式 `graphic-primitives-v2`，坐标只能来自确定性 CV 或经过源像素验证的矢量 refinement。

模型输出只能成为 `semantic_candidate` 或 `specialized_svg_candidate`。它不能决定面板排版，也不能直接成为几何权威。生活化剪影必须拆出人物/器物/附件等语义部件及其拓扑；只有外轮廓的 path 不满足语义层。标准汉字、字母和数字必须保存为 `textGlyph`。

正确答案保存在 evaluation 隔离层，用于检查选项映射和重绘后答案是否保持；给解题模型的输入必须排除 answerLabel，防止答案泄漏。

最终 `accepted` 必须同时通过来源哈希、面板/选项数、拓扑、空心/实心、箭头、文字、方向、精确角、像素贴合、答案保持和前端契约门禁。任一项 pending/fail 时仍为 `repair_pending`。
