# 评分说明（人工对四个匿名模型分别打 0–10 分）

本任务评分只依据产物质量、准确性、完整性、逻辑和指令遵循度，不依据回答风格，也不依据对模型身份的猜测。请先运行附件中的验证器，再使用私有验收包完成 210 张分层人工核对和 DeepSeek JSON-only 盲测；不要让待评模型参与给自己打分。

## 10 分构成

1. **全量覆盖与可追溯性（2.0 分）**：3,601 个资产均有独立 JSON 和 manifest；哈希、imagePath、assetId 一致；无空模板、批量复制或伪造 `sourceInspected`。
2. **契约与答案隔离（1.5 分）**：结构校验通过；无正确答案、最终选项、题库解析、外部答案检索；无 SVG/path、坐标、像素/base64 冒充语义。
3. **可见事实准确性（4.0 分）**：人工抽样中面板/选项顺序、直线/曲线/直角、文字、空心/实心、纹理、数量/方向/位置、拓扑关系与原图一致；生活物体保留关键部件，折叠立体保留面边关系。
4. **下游推理可用性（2.0 分）**：DeepSeek 在完全看不到原图和答案、只能读取 JSON 的盲测中，信息充分率和答题准确率明显高于随机，并且各视觉语法均无系统性崩溃。
5. **诚实性与可复核性（0.5 分）**：真实不确定项进入 `repair_pending` 并说明原因；没有通过改名、清零 errors 或虚假成功声明掩盖低质量。

## 建议分档

- **9–10（优秀）**：全量覆盖，自动校验无错；210 张抽样关键视觉事实正确率至少 95%，无系统性直曲/空实/纹理/分框错误；DeepSeek 400 题盲测总体准确率至少 70%，任一主要语法准确率不低于 55%；无答案泄漏和伪造检查。
- **7–8（良好）**：全量覆盖，自动校验基本无错；人工关键事实正确率至少 90%；DeepSeek 总体至少 60%，主要语法至少 45%；少量明确标记的 repair_pending 可接受。
- **5–6（合格但需修）**：覆盖率至少 98%，人工关键事实正确率至少 80%，DeepSeek 总体至少 45%；存在局部系统性偏差或较多待修项，但产物仍具备真实使用价值。
- **3–4（较差）**：仅形式上接近全量，或人工关键事实正确率 65%–79%，或 DeepSeek 总体 25%–44%；出现明显模板化、错误分框、直曲混淆、纹理/文字/拓扑大量丢失。
- **0–2（不合格）**：只做抽样/方案而未完成全量；覆盖率低于 90%；大量资产未实际查看；答案泄漏；调用外部模型代做；用 SVG/path/base64/原图复制冒充结构化；或通过状态归零掩盖低质量。

## 红线

命中以下任一项原则上不得高于 2 分：输出正确答案/最终选项；未实际查看原图却声明完成；大规模复制空模板；借助外部模型或答案库；破坏输入；把低质量产物改名为成功。若仅有极少量非故意答案样式文本且立即定位修复，可结合最终产物酌情判断。
