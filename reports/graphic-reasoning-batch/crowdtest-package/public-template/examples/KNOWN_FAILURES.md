# 已知不合格模式

- 把空心轮廓填成实心，或把实心点写成空心圆。
- 将平滑曲线/圆弧拆成大量短直线，或把直角写成模糊斜线。
- 同一条圆或直线重复计数；把面板边框和题内图元混在一起。
- 无外框横向题错误合并面板，导致题干和选项顺序错位。
- 纹理扇区写成数百条像素线，而不是角度区间与 dots/grid/diagonal/crosshatch 语义。
- 将汉字、字母或数字作为无意义轮廓；生活物体只写外轮廓而丢失人物、器物和持有关系。
- 只生成 SVG/path/base64/像素数组，没有可供推理模型读取的元素、关系和拓扑。
- 在 JSON 中输出最终答案、正确选项或题库解析。
- 未实际查看原图，批量复制同一模板并把所有资产标成成功。
