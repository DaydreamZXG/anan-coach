## 处理原则

图片不能全部用同一种方式重绘：

1. 统计图和表格只抽取数据与元数据，由确定性图表组件排版。
2. 几何、逻辑、科学示意图和符号网格先用 CV 分割，再生成 `graphic-primitives-v2`；坐标和面板框架不交给模型猜。
3. 照片、文物、艺术作品和复杂地图保留原始像素，同时补 OCR、区域标注和语义元数据。把它们重新“画一张”会改变题意。
4. 任何低置信或答案敏感图进入 `needs_review`，不生成看似相近的替代图。
5. 公式图片走讯飞公式识别，输出可渲染公式；识别结果未核验时仍展示原图。
